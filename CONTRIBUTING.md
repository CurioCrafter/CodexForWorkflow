# Contributing

CodexForWorkflow is open source under the MIT License.

Issues, bug reports, and suggestions are welcome. Use the issue templates so
mode, environment, screenshots, and logs are clear.

For pull requests:

- keep changes focused;
- run `npm run check`;
- include screenshots for renderer/UI changes;
- call out any safety, privacy, or approval-flow impact;
- do not include secrets, tokens, private screenshots, or proprietary code.

Public pull requests are not automatically accepted, and submitting code does
not give you ownership rights in this project.

By submitting an issue, suggestion, patch, pull request, design, test case, or
other contribution, you agree that Andrew Rainsberger may use, modify, publish,
and incorporate it into CodexForWorkflow without payment, restriction, or
obligation to you.

Do not submit confidential information, secrets, proprietary code, or anything
you do not have the right to submit.
